# java-calculator-precourse
## 우아한 테크코스 프리코스 8기 1주차 미션: 문자열 덧셈 계산기

---

## 1. 주요 기능 목록
- [x] 사용자 입력을 받아 문자열 계산 수행
- [x] 기본 구분자(`,`, `:`)로 숫자 분리 및 합산
- [x] 커스텀 구분자 지원 (`//구분자\n` 형식)
- [x] 잘못된 입력 시 `IllegalArgumentException` 발생

---

## 2. 구현 시 주요 고려사항

### 객체지향 설계
- **책임 주도 설계(RDD)**: 각 클래스가 명확한 책임을 가지며, 행동 위주로 도메인을 분리
- **매직 넘버/매직 스트링 제거**: 하드코딩된 값을 상수로 분리하여 가독성과 유지보수성 향상
- **Tell, Don't Ask 원칙**: 객체의 상태를 묻지 않고 행동을 요청하여 캡슐화 강화

---

## 3. 예외 처리
> 모든 예외는 `IllegalArgumentException`을 상속하여 요구사항 준수

### 커스텀 구분자 형식 오류
- `\n`이 없거나 구분자가 정의되지 않은 경우
- `//구분자\n` 형식을 위반한 경우

### 수식 형식 오류
- 구분자로 시작하거나 끝나는 경우
- 지정한 구분자 외의 구분자 사용
- `<숫자 구분자 숫자>` 형식 위반

### InvalidNumberException
- 숫자가 아닌 값 입력 시

### MinusNumberException
- 음수 입력 시

---

## 4. 추가 구현 사항
- **다중 문자 커스텀 구분자 지원**
  - 예: `//:+:\n1:+:2:+:3` → 결과: 6
- **개행 문자를 커스텀 구분자로 사용 가능**
- **정규표현식에서 `////n` 사용**
  - 요구사항의 "백슬래시 + n" 표기를 정확히 구현
- **메타 애노테이션 활용**
  - `@BasicFormulaTest`: 기본 구분자 테스트
  - `@CustomFormulaTest`: 커스텀 구분자 테스트
  - 테스트 케이스의 의도를 명확히 구분
