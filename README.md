# java-calculator-precourse
## 우아한 테크코스 프리코스 8기 1주차 미션: 문자열 덧셈 계산기

---

## 1. 기능 목록 (요구사항 명세)
- [x] 문자열 계산기는 사용자의 입력을 받을 수 있어야 합니다.
- [x] 문자열은 기본적으로 `,` `:` 를 기준으로 나눕니다.
- [x] 문자열 계산기는 구분자를 기준으로 숫자를 나눠서 더합니다.
- [x] 문자열 계산기는 커스텀 구분자를 받을 수 있다. `//`와 `\n` 사이에 있는 값을 지정합니다.
- [x] 잘못된 값을 입력하면 IllegalArgumentException을 발생시킵니다.

---

## 2. 구현 시 주요 고려사항

### 객체지향 설계
- **책임 주도 설계(RDD)**: 각 클래스가 명확한 책임을 가지며, 행동 위주로 도메인을 분리 하고자 노력 했습니다.

---

## 3. 예외 처리

### IllegalArgumentException 발생 조건
- **커스텀 구분자 형식 오류**:
    - `\n`이 없거나, 정의한 구분자가 없을 경우
    - `//구분자\n` 형식과 다른 입력
- **수식 형식 오류**:
    - 구분자로 시작하거나 끝나는 경우
    - 지정한 구분자와 다른 구분자 사용할 경우
    - `<숫자 구분자 숫자>` 형식을 위반할 경우

---

## 4. 추가 구현 사항
- 커스텀 구분자 정의 시, **여러 개의 문자를 묶음**으로 사용 가능합니다.
    - 입력 > `//:+:\\n1:+:2:+:3` 
    - 출력 > 결과 : 6
